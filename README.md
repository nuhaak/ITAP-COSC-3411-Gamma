# CLI Calculator

A minimalist, lightweight command-line calculator built in Python. Designed for rapid mathematical evaluations directly from your terminal, prioritizing simplicity, speed, and clean code execution.

## Key Features
#### Core Arithemtic: 
Supports standard operations (addition, subtraction, multiplication, division).

#### Instant Execution: 
Evaluates expressions directly via command-line arguments or an interactive prompt.

#### Zero Dependencies: 
Built entirely using Python's standard library for maximum portability.
